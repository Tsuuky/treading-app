# Dépendances npm du projet

Ce fichier liste toutes les dépendances nécessaires pour ce projet.

## Installation complète (recommandé)

```bash
npm install
```

## Dépendances de production (`dependencies`)

- `bcryptjs` `^2.4.3`
- `better-sqlite3` `^11.7.0`
- `lightweight-charts` `^5.0.8`
- `next` `16.1.6`
- `react` `19.2.3`
- `react-dom` `19.2.3`

## Dépendances de développement (`devDependencies`)

- `@types/jest` `^29.5.14`
- `@types/node` `^20`
- `@types/react` `^19`
- `@types/react-dom` `^19`
- `eslint` `^9`
- `eslint-config-next` `16.1.6`
- `jest` `^29.7.0`
- `node-mocks-http` `^1.16.2`
- `ts-jest` `^29.2.5`
- `tsx` `^4.19.2`
- `typescript` `^5`

## Optionnel : commandes d’installation manuelle

### Production uniquement
```bash
npm install bcryptjs better-sqlite3 lightweight-charts next react react-dom
```

### Développement uniquement
```bash
npm install -D @types/jest @types/node @types/react @types/react-dom eslint eslint-config-next jest node-mocks-http ts-jest tsx typescript
```
